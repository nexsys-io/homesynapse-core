# recovery-card-v1 — the recovery card, design of record (v1, 2026-10-09)
This folder is the design specification, the fields note and the static mockups for the recovery card — one device's recovery line in the three words of `VOCAB: a` (Reporting · Quiet since <t> (asked, answered) · Not responding since <t> (asked twice, no answer)), the passive class, the fifth state (seeded dark, never asked), the contract sentence per class and the act "open a window for this device": `SPEC.md` (§1–§12), `FIELDS.md` (the three field tables) and `states.html` (every state and every moment of the act, dark and light, self-contained, no scripts).
It is not shipped and not bundled: nothing here is imported by `src/`, the Vite build or the CI gate; the product name appears only as the token `{{NAME}}`.
